## Root Cause Analysis

### Bug 1 — Deterministic off-by-one (`dummy.py`)

| | Detail |
|---|---|
| **File** | [`sample_repo/dummy.py:3`](sample_repo/dummy.py:3) |
| **Symptom** | `assert add(2, 3) == 5` → `AssertionError: 6 == 5` |
| **Root cause** | The implementation was `return a + b + 1` — a hard-coded `+ 1` offset that corrupted every result |
| **Fix** | Removed the spurious `+ 1`: `return a + b` |

### Bug 2 — Flaky randomness (`test_flaky_timing.py`)

| | Detail |
|---|---|
| **File** | [`sample_repo/tests/test_flaky_timing.py:5`](sample_repo/tests/test_flaky_timing.py:5) |
| **Symptom** | `assert random.random() > 0.3` fails ~30 % of runs non-deterministically |
| **Root cause** | The test asserts on an unseeded RNG; any value in `[0.0, 0.3]` (probability ≈ 30 %) causes failure |
| **Fix** | Replaced global `random.random()` with a locally-seeded `random.Random(42).random()` — seed 42 always produces `0.6394…`, which is unconditionally `> 0.3` |
